# FilterSetMobileSearch

Mobile search filters. Parked: Filter Set still to be merged.

Figma: **Organisms/Filter Set/Mobile (Search)** (node `31:503`), 1 variant.

## Use it

`window.BN.FilterSetMobileSearch` renders the Figma design variant by variant. Choose a variant with the props below. Values match the Figma property values letter for letter.

It has no variant props.

Pass `label` to replace the **Tab text** text, or `texts` keyed by layer name to replace any other copy.

## Notes

- Replaces `M_SearchFilters` from the first build.
- Colours, spacing and corners use the `bn-` tokens wherever Figma binds a variable. Text uses the values of its Figma text style.
