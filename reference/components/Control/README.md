# Control

A round expand and collapse control.

Figma: **Atoms/Control** (node `50:508`), 2 variants.

## Use it

`window.BN.Control` renders the Figma design variant by variant. Choose a variant with the props below. Values match the Figma property values letter for letter.

| Prop | Figma property | Values (first is the default) |
|---|---|---|
| `upDown` | Up/Down | `Down`, `Up` |

## Variants

- Up/Down=Down
- Up/Down=Up

## Notes

- Colours, spacing and corners use the `bn-` tokens wherever Figma binds a variable. Text uses the values of its Figma text style.
