# FilterSetDesktop

The desktop filter bar with category and author filters. Parked: Filter Set still to be merged.

Figma: **Organisms/Filter Set/Desktop** (node `13:651`), 1 variant.

## Use it

`window.BN.FilterSetDesktop` renders the Figma design variant by variant. Choose a variant with the props below. Values match the Figma property values letter for letter.

It has no variant props.

Pass `label` to replace the **Category:** text, or `texts` keyed by layer name to replace any other copy.

## Notes

- Replaces `DT_FilterSet` from the first build.
- Colours, spacing and corners use the `bn-` tokens wherever Figma binds a variable. Text uses the values of its Figma text style.
