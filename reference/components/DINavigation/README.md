# DINavigation

The Data & Insights secondary navigation bar.

Figma: **Organisms/D&I Navigation/Desktop** (node `2:426`), 1 variant.

## Use it

`window.BN.DINavigation` renders the Figma design variant by variant. Choose a variant with the props below. Values match the Figma property values letter for letter.

It has no variant props.

Pass `label` to replace the **Lists** text, or `texts` keyed by layer name to replace any other copy.

## Variants

- Desktop

## Notes

- Replaces `DT_NavSecondaryDI` from the first build.
- Colours, spacing and corners use the `bn-` tokens wherever Figma binds a variable. Text uses the values of its Figma text style.
