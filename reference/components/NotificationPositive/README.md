# NotificationPositive

A green confirmation bar for a successful action.

Figma: **Molecules/Notification/Positive** (node `12:305`), 1 variant.

## Use it

`window.BN.NotificationPositive` renders the Figma design variant by variant. Choose a variant with the props below. Values match the Figma property values letter for letter.

It has no variant props.

Pass `label` to replace the **Text** text, or `texts` keyed by layer name to replace any other copy.

## Variants

- Positive

## Notes

- Replaces `DT_NotificationPositive` from the first build.
- Colours, spacing and corners use the `bn-` tokens wherever Figma binds a variable. Text uses the values of its Figma text style.
