# Divider

A rule for separating content: solid, dashed, stub or vertical.

Figma: **Atoms/Divider** (node `59:582`), 4 variants.

## Use it

`window.BN.Divider` renders the Figma design variant by variant. Choose a variant with the props below. Values match the Figma property values letter for letter.

| Prop | Figma property | Values (first is the default) |
|---|---|---|
| `style` | Style | `Dashed`, `Stub`, `Solid`, `Vertical` |

## Variants

- Style=Dashed
- Style=Stub
- Style=Solid
- Style=Vertical

## Notes

- Colours, spacing and corners use the `bn-` tokens wherever Figma binds a variable. Text uses the values of its Figma text style.
