# LockedContent

A prompt shown in place of subscriber-only content.

Figma: **Molecules/Locked Content** (node `380:965`), 1 variant.

## Use it

`window.BN.LockedContent` renders the Figma design variant by variant. Choose a variant with the props below. Values match the Figma property values letter for letter.

It has no variant props.

Pass `label` to replace the **text** text, or `texts` keyed by layer name to replace any other copy.

## Variants

- Locked Content

## Notes

- Colours, spacing and corners use the `bn-` tokens wherever Figma binds a variable. Text uses the values of its Figma text style.
