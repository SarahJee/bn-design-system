# SearchTabs

Tabs for switching search result types.

Figma: **Molecules/Search Tabs/Desktop** (node `2:628`), 1 variant.

## Use it

`window.BN.SearchTabs` renders the Figma design variant by variant. Choose a variant with the props below. Values match the Figma property values letter for letter.

It has no variant props.

Pass `label` to replace the **All Results** text, or `texts` keyed by layer name to replace any other copy.

## Variants

- Desktop

## Notes

- Replaces `DT_SearchTabs` from the first build.
- Colours, spacing and corners use the `bn-` tokens wherever Figma binds a variable. Text uses the values of its Figma text style.
