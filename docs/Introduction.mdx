# BN Design System

These are the Business News components from the BN Component Library in Figma, built as Drupal single directory components (Twig and CSS).

- **Foundations** has the icon set. Colours, type and spacing live in `tokens/tokens.css` as CSS custom properties, using the Figma variable names (`--bn-brand-primary`, `--bn-space-md`).
- **Components** and **Forms** are the core set: buttons, action links, follow, bookmark and share, subscribe toggles, form fields, checkbox, radio, search, tags, filters, sort toggle, project status, divider and notification.
- Every story uses the same Twig file Drupal renders, so what you see here is what the site gets.

See the README in the repository for Drupal setup, the Figma mapping and the decisions still to review.
